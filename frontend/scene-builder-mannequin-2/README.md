# MakeHuman scene 2

MakeHuman editor with camera XYZ position/rotation, free orbit, and six torso-relative camera presets. Select a mannequin and use Move to drag its red, green, and blue position arrows. Rotation handles remain disabled; use Properties for joint rotations.

Open through **MakeHuman scene 2** in the app or `/scene-builder-mannequin-2/index.html`. Runtime rig, poses, assets, styles, export and bridge modules are shared with the original MakeHuman editor; project format remains compatible.
